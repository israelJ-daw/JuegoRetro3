
# Cosmic Defender: Retro Arcade

¡Bienvenido a **Cosmic Defender**! Un videojuego de naves estilo arcade desarrollado con tecnologías web modernas.

## 🎮 Cómo Jugar

Tu misión es defender la Tierra de **10 oleadas** de invasores alienígenas. La dificultad aumenta progresivamente.

**Controles:**
- **Flecha Izquierda / Derecha**: Mover la nave lateralmente.
- **Barra Espaciadora**: Disparar láseres.
- **Enter**: Iniciar juego o reiniciar.

**Objetivo:**
- Destruye todas las naves enemigas para pasar de nivel.
- En el Nivel 10 te enfrentarás al **Jefe Final**.
- Tienes **3 vidas**. Evita los disparos rojos y que las naves toquen tu posición.
